# Memory Bank

プロジェクトの知識ベース。Cline（AIアシスタント）がコンテキストを維持するための永続的な情報源。

## ファイル一覧

| ファイル | 内容 | 更新タイミング |
|---------|------|---------------|
| `projectbrief.md` | プロジェクトの概要・目的・対象プラットフォーム | プロジェクト開始時・スコープ変更時 |
| `activeContext.md` | 現在の状況・進捗・今後の課題 | 作業完了時・状況変化時 |
| `techContext.md` | 技術的知見・トラブルシューティング・UBXプロトコル詳細 | 新たな知見を得た時 |
| `systemPattern.md` | システム設計・アーキテクチャ・ディレクトリ構成 | 設計変更時 |

## 更新ルール

1. **作業完了時**: `activeContext.md` の進捗を更新
2. **新知見獲得時**: `techContext.md` に追記
3. **構成変更時**: `systemPattern.md` を更新
4. **スコープ変更時**: `projectbrief.md` を更新
